# Peach Tarot 🍑

A soft, skeuomorphic website for gentle tarot guidance.

**Live site (once Pages is enabled):**  
https://getquicker.github.io/peach-tarot/

## Features

- Wooden table + parchment interface with soft peach tones
- Interactive daily card draw with 3D flip animation
- All 22 Major Arcana with gentle, kind interpretations
- Spreads overview and private reading contact section
- Fully responsive

## Local use

Just open `index.html` in a browser.

## Publish with GitHub Pages

1. Go to the repository **Settings → Pages**
2. Under **Source**, select **Deploy from a branch**
3. Choose branch **main** and folder **/ (root)**
4. Click **Save**

The site will be available at:  
**https://getquicker.github.io/peach-tarot/**
